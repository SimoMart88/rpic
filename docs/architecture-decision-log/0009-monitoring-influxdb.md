# Use InfluxDB for the time series data of Device monitoring system

Date: 27/05/2025

# Problem
Find the most appropriate storage for the time series data generated by the Device monitoring system

# Decision
* Use version 1.x of InfluxDB (https://github.com/influxdata/influxdb/tree/master-1.x)
  * Latest version available RaspberryPi 1b ()

# Consequences
* System will relay on an ancient version of InfluxDB
* No out-of-the-box support is available for Django
  * Python client support will be used (https://github.com/influxdata/influxdb-python)
    * System will relay on an ancient version of InfluxDB Python Client (repository was archived in 2024)

# Considered alternatives
* Use version 3.x of InfluxDB (https://github.com/influxdata/influxdb/tree/master)
  * Package is not available for Raspberry Pi OS (Legacy) - Debian version: 11 (bullseye)
  * Effort required for manual build is unknown but can be high
* Use TimescaleDB (https://github.com/timescale/timescaledb)
  * Package is not available for Raspberry Pi OS (Legacy) - Debian version: 11 (bullseye)
  * Effort required for manual build is unknown but can be high
